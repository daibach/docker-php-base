# docker-php-base

Base PHP images published to Docker Hub as `cedyrn/php-parent:<variant>`, e.g. `cedyrn/php-parent:8.4-apache-cron`.

Each variant has its own folder containing a Dockerfile. The Dockerfiles are generated by `generate.sh`.

## Builds

Images are built by GitHub Actions (`.github/workflows/build.yml`):

| Trigger | Result |
|---|---|
| Pull request | Builds and tests every variant. Nothing is pushed. |
| Push to `main` | Builds, tests and pushes every variant. |
| Weekly (Monday 04:00 UTC) | Same as a push to `main`, to pick up upstream PHP and Debian updates. |
| Manual (Actions → Build images → Run workflow) | Same as a push to `main`. Use this to pick up an urgent upstream patch. |

Each image is checked by `tests/smoke-test.sh` before it is pushed. If a test fails, that variant's tag is not updated. The script can be run locally against a built image:

```sh
docker build -t php-parent-test:8.4-apache 8.4-apache
tests/smoke-test.sh php-parent-test:8.4-apache
```

Apache tests are selected when the image name contains `apache`.

### Configuration

The workflow pushes using a Docker Hub personal access token with Read & Write permission:

- `DOCKERHUB_USERNAME`: repository variable
- `DOCKERHUB_TOKEN`: repository secret
